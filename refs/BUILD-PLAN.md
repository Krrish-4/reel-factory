# Build plan

46 animations across 17 references that our component library cannot produce, clustered into **9 components**.

Generated by `refs/cluster-build.py`. The raw per-reference lists are in each `*.report.md`; this is the deduplicated engineering view.

## Recommended order

1. StaggeredGrid — Universal layout utility that instantly unlocks multiple grid and matrix references with minimal dev effort.
2. CardCarousel — High leverage component that solves continuous and stepped image/card transitions across many ads.
3. SpectrumSlider — Essential for performance/explainer ads showing scores, scales, and comparative spectrums.
4. ScanOverlay — Unlocks all scientific/AI diagnostic video hooks that drive high engagement in explainer ads.
5. DiagramAnnotation — Essential for technical breakdown overlays, callouts, and feature dimensions.
6. AnimatedBarChart — High-value data visualization component built on top of existing CountUp primitive.
7. SplitPanelShift — Quick to build, solves panel comparison and swap transitions.
8. SyncProgressTimeline — Low effort add-on for routine and timeline explainer scenes.
9. TypewriterInput — Specialized call-to-action component for search bar outro screens.

## Components

### `CardCarousel`

Translates a sequence of cards or image swatches continuously or step-by-step along a vertical or horizontal track.

- **leverage** high · **effort** medium · **used by 7 references**
- **mechanic** Translates a flex/grid container along X or Y with spring-based step pauses or constant linear velocity.
- **why one component** These are all variations of scrolling image or card strips. Direction and step vs. continuous motion are simple prop configurations.
- **build** Build a flex container accepting children array. Prop 'mode' accepts 'continuous' (infinite scroll loop) or 'stepped' (snapping to index via spring).
- **unlocks** Product galleries, logo tickers, testimonial lists, and multi-option selection carousels.
- **absorbs 7**: Horizontal Celebrity Scroll; Overlapping Portrait Cards Slide; Stepped Vertical Scroll; Vertical List Scroll; Lip Scale Carousel Shift; Horizontal Portrait Slide; Step Selection Stack Deck

### `SpectrumSlider`

Animates a pointer handle along a horizontal or vertical axis to indicate a position, threshold, or range on a scale.

- **leverage** high · **effort** medium · **used by 6 references**
- **mechanic** Interpolates pointer translate offset along an axis synced with dynamic value counter text and track fill highlight.
- **why one component** All of these feature a fixed visual track with an indicator sliding along it to reflect dynamic data or user placement.
- **build** Use Remotion interpolate() to map video frame to percentage position. Support optional start/end range highlighting and top/bottom badge callouts.
- **unlocks** Price range scales, feature benchmarks, risk indicators, and percentage comparison bars.
- **absorbs 7**: Expectations Ratio Bar Fill; Density Spectrum Pointer; Slider Rating Pointer; UI Slider Control; Profile Color Bar Reveal; UV Sensitivity Gauge Pointer; SPF Range Target Bar

### `ScanOverlay`

Sweeps a scanning line, target reticle, or grid overlay over media to simulate computer vision analysis.

- **leverage** high · **effort** medium · **used by 5 references**
- **mechanic** Translates a linear gradient mask or bounding box vertically/horizontally over a target element with optional HUD text.
- **why one component** All these patterns simulate a diagnostic scan by sweeping an overlay element (line, grid, box, or crosshair) across an image.
- **build** Implement as an overlay component using absolute positioning. Animate scan bar transform Y/X from 0% to 100% and render customizable vector grid/reticle textures.
- **unlocks** Tech product scans, AI feature highlights, document inspection visuals, and diagnostic breakdowns.
- **absorbs 6**: Facial AI Feature Scan Overlay; Grid Scan Overlay; Face Scanner Box; Piercing Target Reticle Overlay; HUD Analysis Overlay; Complex Face Analysis Overlay

### `DiagramAnnotation`

Traces vector arrows, dimension lines, or callout indicators on top of media to highlight technical features.

- **leverage** high · **effort** medium · **used by 5 references**
- **mechanic** Animates SVG path strokeDashoffset to draw lines and arrows while springing target badges into view.
- **why one component** These rely on drawing SVG lines, pointers, or brackets between origin and target coordinates synchronized with label pop-ins.
- **build** Combine TrimPath mechanic with coordinate-based SVG markers (arrows, brackets, dimension tick marks). Accept start/end points as props.
- **unlocks** Product specs, anatomical diagrams, architectural callouts, and explanatory flowcharts.
- **absorbs 6**: Mannequin & Label Pop-In with Arrow; Bracket Label Draw-On; Flowchart Arrow Draw; Graph Path Follower; Dimension Lines & Arrows; UV Ray Penetration Diagram

### `StaggeredGrid`

Lays out child cards or image tiles in a multi-column grid and reveals them with a staggered spring pop animation.

- **leverage** high · **effort** small · **used by 4 references**
- **mechanic** Calculates grid layout positions and applies a staggered delay spring scale and opacity enter animation.
- **why one component** Whether 2x2, 3x4, or 3-column, these are all CSS grid layouts staggering child pop-in animations.
- **build** Wrap children in a CSS Grid container. Calculate entry delay per child using `index * staggerFrames` and apply spring scale from 0 to 1.
- **unlocks** Feature grids, photo collections, variant selections, and summary matrix screens.
- **absorbs 4**: 2x2 Image Grid Stagger Pop; Staggered Grid Pop-In; Staggered Grid Reveal; Skin Texture Split Panel

### `AnimatedBarChart`

Animates vertical or horizontal data bars growing from zero alongside dynamic value labels and badges.

- **leverage** high · **effort** medium · **used by 4 references**
- **mechanic** Staggered scale transform from baseline tied to animated counter text and top badge anchors.
- **why one component** These share the same underlying chart structure: growing bar geometries with attached numerical and visual labels.
- **build** Use scaleY/scaleX with `transformOrigin: 'bottom'` (or left). Integrate spring dynamics for bar growth and combine with CountUp for value labels.
- **unlocks** Survey results, performance metrics, statistical comparison charts, and depth/level indicators.
- **absorbs 3**: Bar Graph Vertical Rise with Badges; Bar Chart Growth; PA Protection Depth Beams

### `SplitPanelShift`

Animates two or more image panels sliding relative to each other to show side-by-side contrast or realignment.

- **leverage** medium · **effort** small · **used by 4 references**
- **mechanic** Translates adjacent masked child layers in sync or opposing directions with dynamic clipping boundaries.
- **why one component** All these mechanics shift adjacent panels or swappable frames relative to a central split point.
- **build** Use flex or CSS relative positioning with mask-image/overflow-hidden. Interpolate translation offset per panel using spring physics.
- **unlocks** Before/after comparisons, image swap transitions, and split-screen feature highlights.
- **absorbs 4**: Split Face Comparison; Asymmetry Adjustment; Photo Position Swap; Panel Shift

### `SyncProgressTimeline`

Fills a linear progress bar over time while moving a synchronized tracking icon or cursor along its path.

- **leverage** low · **effort** small · **used by 1 references**
- **mechanic** Interpolates bar width percentage in lockstep with an absolute X-position translate on an attached tracking element.
- **why one component** Combines a progress bar fill with a synchronous cursor translate.
- **build** Map frame to 0-100% progress. Bind both indicator translate X and progress bar width to the same progress spring/interpolation value.
- **unlocks** Video timeline scrubbers, step progress indicators, and routine duration timers.
- **absorbs 1**: Application Routine & Timeline Sweep

### `TypewriterInput`

Types out search terms or text string characters inside a mockup UI input bar with a blinking cursor.

- **leverage** low · **effort** small · **used by 1 references**
- **mechanic** Slices text string based on frame count and toggles a cursor element opacity on a loop.
- **why one component** Distinct text typing mechanism framed within a search box UI container.
- **build** Calculate current visible character count with `Math.floor(frame / framesPerChar)`. Render active string + blinking SVG cursor line.
- **unlocks** Search call-to-actions, code typing effects, and terminal UI simulations.
- **absorbs 1**: Search Bar Typing Outro

## Judged not worth building

- **Globe Spin & Text Reveal** — Globe graphic rotation is best handled as a pre-rendered Lottie/video asset; text reveal is already covered by standard SectionHeadline or Reveal components.
- **Map Navigation & Portrait Slide** — Too hyper-specific. Better composed ad-hoc using existing Camera pans combined with PopIn for coordinate markers.
- **Soft Cloud Scallop Mask Frame** — Decorative visual asset overlay rather than reusable animation code logic. Can be achieved with standard CSS mask-image.
- **Radial Palette Pop-In** — Niche radial geometry layout. Easily achieved by placing PopIn items around a absolute center using simple CSS transform rotation offsets.
- **Clothing Color Swap** — Video/image filter transition rather than custom animation primitive. Achieve via standard CSS hue-rotate filter or overlapping video crossfade.
- **Feature Toggle Stack** — Already fully covered by the existing AnimatedCheckList component.
