# Making a Refina reel

`CLAUDE.md` is the contract and `docs/reel-invariants.md` is the list of failure
modes this repo has actually shipped. Read both. This skill routes to the
workflow for the stage you are at.

## One rule above the others

**Never move a metric instead of fixing the video.** A reel measured 85% frozen,
so a slow zoom was added to every static beat to bring the number down. It did
not work — and it would not have been a fix if it had. Rule P.

Everything below asserts facts. Nothing scores taste. The one step that judges
taste is a human looking at a phone-sized contact sheet, and it is deliberately
unautomated.

## Route by stage

**Writing or revising a script** → [Script](./reel-script/REFERENCE.md)
The shape all 14 corpus explainers share, the pacing targets, and how a study
may be cited - with a recorded source, checked by gen/check-citations.py.

**Adding or re-timing a voiceover** → [Voiceover](./reel-voiceover/REFERENCE.md)
`gen-voiceover.py`, the script-file format, the five failure modes found in the
TTS pipeline, and how beat bounds derive from the cue table so no frame is typed.

**Generating images** → [Assets](./reel-assets/REFERENCE.md)
gflow, the casting fix, the three-axis screen, the registry, and the framing
contract that stopped the same head appearing at three sizes.

**Writing or editing a composition** → [Build](./reel-build/REFERENCE.md)
The spec → compiler architecture, the beat library, occupancy, shot variety, the
type floor, and where to look for a component before writing one.
**Choosing which animation carries which script lines** →
`docs/beat-catalog.md` (generated by `python gen/beat-catalog.py`): every
beat composition, and the exact lines it has carried in every past reel.

**Adding sound** → [Sound](./reel-sound/REFERENCE.md)
Which palette suits which beat, the tail ramp, and deriving cues from the beat
table.

**Rendering** → [Render](./reel-render/REFERENCE.md)
The gate, stills before render, and the settings that are not negotiable.

**Judging a finished cut** → [Review](./reel-review/REFERENCE.md)
`refs/analyse.py`, reading the Gemini record for what it got *wrong*, the
resolution trap, and the corpus figures that are not targets.

**Touching a reel that already exists** →
[Compositions](./reel-compositions/REFERENCE.md)
The five shipped reels and the invariants locked into each. Two are signed off
and must not be changed to satisfy a new check.

## The checks

```
npm run check      # preflight: assets, legibility, shot plan
npm run verify     # + postflight: frames, motion, face size, phone sheet
npm run corpus     # regenerate corpus stats and shot bands
```

`gen/check.py` runs them in order and exits non-zero. It ends by telling you to
look at the phone sheet, because nothing above that line can tell you whether a
label is readable, an annotation is on the right feature, or a beat shows what
it claims.
