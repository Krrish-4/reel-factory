# THE ENGINE, AND IT IS THE SAME ONE nose.txt AND lips.txt ALREADY RUN:
#   A feature is never read on its own. It is read against the two features
#   next to it. Change the feature and the neighbours RE-READ without moving.
#   The celebrity is a hook, not a new argument.
#
# THE SLOTS
#   {{SUBJECT}}      the named person, in the hook and once in the CTA
#   {{FEATURE}}      the feature being analysed
#   {{NEIGHBOUR_A}}  what sits above/beside it and is read against it
#   {{NEIGHBOUR_B}}  what sits below/beside it and is read against it
#   {{MECHANISM}}    the geometric reason, in one reproducible sentence
#   {{RANGE}}        what the Refina demo dials, e.g. "volume", "projection"
#   {{SELF_TEST}}    a physical action that reproduces {{MECHANISM}} in 3s
#   {{VIEWER_WORRY}} the insecurity the feature attaches to, in the viewer
#   {{WRONG_CAUSE}}  what they think causes it, and beats 3-5 disprove
#
# BEAT 3 IS THE EVIDENCE SLOT, AND IT TAKES EITHER OF TWO THINGS.
#
#   A CITED SOURCE, if one has actually been read. Citations are allowed --
#   reel-script/REFERENCE.md dropped the old blanket ban, 8 of 21 references
#   run on exactly this, and kit/CitationCard is built for it. Record it above
#   the claim and gen/check-citations.py will enforce the receipt:
#
#       # SOURCE: Author et al. (2021), Journal. https://doi.org/10.xxxx/yyyy
#       In that trial, participants rated them higher.          | 0.30
#
#   A MECHANISM, otherwise -- and this is the default, because it is free and
#   it is what both shipped explainers run on. One geometric sentence the
#   viewer can reproduce on their own face, which beat 9 then has them do.
#
# WHAT IS BANNED IS THE SHAPE WITHOUT THE SUBSTANCE. The brief asked to "link
# it to science"; "full lips signal fertility" is not that link, because it
# cites nothing and is contested besides. Cite a paper or show a mechanism --
# never imply a paper. And the check cannot tell you a source is real or says
# what you claim: someone has to have read it.
#
# BEATS 8 AND 9 ARE NOT OPTIONAL. Every one of the 14 corpus explainers carries
# a nuance that complicates its own claim, and five carry a self-test — the most
# saveable moment in the format. reel-script/REFERENCE.md: do not cut them for
# time. Cutting the demo beat to length is the correct trade, not cutting these.
#
